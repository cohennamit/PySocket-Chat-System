🚀 PySocket Chat System | תיעוד פרויקט מלא
מערכת צ'אט מרובת משתתפים (Multi-Client) מבוססת TCP/IP, הכוללת ארכיטקטורת שרת-לקוח מלאה, ממשק גרפי (GUI) ואוטומציה. נכתב ב-Python (Standard Lib).
✨ תכונות מרכזיות (Features):
🌐 Real-Time: שימוש ב-TCP Sockets לתעבורה אמינה.
🧵 Multi-Threading: השרת מנהל כל לקוח ב-Thread נפרד למניעת עומס (Non-blocking).
🔒 סוגי הודעות: תמיכה ב-Broadcast (לכולם) ו-Whisper (פרטי ומוצפן ויזואלית).
🎨 GUI חכם: ממשק tkinter עם צביעה דינמית: 🟦 ציבורי, 🟪 פרטי, ⬜ מערכת.
💾 תיעוד (Logging): שמירה אוטומטית של היסטוריית השיחה לקובץ chat_history.txt.
⚡ אוטומציה: סקריפט main.py שמנהל את כל ה-Lifecycle (הרצה וסגירה).
🛠️ ארכיטקטורה ומבנה קבצים:
📂 main.py (Orchestrator):
"המנהל". משתמש ב-subprocess להרצת תהליכים נפרדים, ומבצע ניטור (Watchdog) לסגירה מסודרת.
🖥️ server.py (Server):
ה"מוח". מבצע bind ו-listen, מנהל את רשימת ה-Sockets המחוברים ומנתב הודעות.
👤 client.py (Client):
צד הלקוח. מריץ שני תהליכונים במקביל: אחד ל-GUI (ממשק) ואחד להאזנה להודעות נכנסות (recv).
📝 chat_history.txt:
מסד הנתונים. קובץ לוגים שנכתב ע"י השרת בזמן אמת.
💻 הסבר טכני (Deep Dive):
🔹 פרוטוקול תקשורת: המערכת עובדת בפורמט טקסטואלי של TARGET:MESSAGE.
• דוגמה לציבורי: ALL:Hello World
• דוגמה לפרטי: Moshe:Secret Message
🔹 מנגנון Watchdog: הקובץ main בודק כל 0.5 שניות האם תהליך השרת חי (poll). ברגע שהשרת נסגר -> מופעלת פקודת taskkill לחיסול מיידי של הלקוחות.
🚀 הוראות הרצה (Usage):
1️⃣ פתחו טרמינל בתיקיית הפרויקט.
2️⃣ הריצו את הפקודה: python main.py
3️⃣ המערכת תפתח אוטומטית 3 חלונות: לוגים של השרת + 2 לקוחות לצ'אט.
🔴 לסגירה: סגרו את חלון ה-Server (ה-X), והמערכת תכבה את כל שאר החלונות אוטומטית.
